| Термин | Значение |
|---|---|
| **Survivors** | Игровая сторона выживших. Задача — продержаться до нуля таймера и выполнить objectives |
| **Killers** | Игровая сторона убийцы. Задача — устранить всех выживших до нуля таймера |
| **Sentinels** | Категория выживших (оглушение, защита) |
| **Supports** | Категория выживших (поддержка команды) |
| **Survivalists** | Категория выживших (личное выживание) |
| **Exclusive** | Персонажи, доступные только разработчикам и участникам проекта; часть играбельна на приватных серверах при наличии V.I.P-геймпасса |

### Чего в файле по-прежнему нет

**Способности остальных 11 выживших и всех 8 убийц постранично не подтверждены.** Причина: персональные страницы `forsaken.wiki` в отрисованном виде занимают 9 фрагментов каждая, а `api.php` и `rest.php/v1` на этом хосте недоступны для загрузки (ответ «File not found»). Выгрузка 21 страницы целиком в рамках одной проверки невозможна.

**Поэтому ростер Forsaken по именам, категориям и статусам — полный, а по способностям — нет.** Явно помечаю это, чтобы не выдавать неполные данные за полные.
