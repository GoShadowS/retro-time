# retro time

Оригинальный матчевый асимметричный хоррор-выживач для Roblox.

- Название: **retro time** (написание не менять).
- Риг: **R6**, авторские анимации.
- Визуальное направление: **retro-slop** — намеренная избыточная стилизация, осознанный коллаж. Свой ретро-гибрид без привязки к конкретным годам Roblox. Читаемость персонажей, угроз, состояний и важных объектов важнее стилистической избыточности.
- Платформы: приоритет — PC, мобильные устройства поддерживаются, консоли пока не в приоритете.

## Серверы и составы

| Сервер | Режим | Состав |
|---|---|---:|
| Default | Default | 1 убийца против 8 выживших |
| Default | **One Bounce** — неожиданное событие на этом же сервере | 8 убийц против 1 выжившего |
| Double Trouble — отдельный сервер | Double Trouble | 2 убийцы против 12 выживших |
| Double Trouble | **Two Bounce** | 12 убийц против 2 выживших |

Default и Double Trouble — один основной режим: базовые правила и цикл одинаковы, различаются состав и баланс. One Bounce и Two Bounce — один режим, Two Bounce — масштабирование для своего состава.

## Основной игровой цикл

Выжившие чинят разные генераторы и выполняют другие задания; прогресс сокращает оставшееся время убийцы или убийц; доступное время зависит от числа живых выживших. Выжившие побеждают, если переживают отведённое время; убийца или убийцы — если устраняют всех до его истечения. В прототипе используется **обратный отсчёт**.

Эта структура **намеренно скопирована** из Forsaken, Bite By Night и Die of Death и **не является оригинальной механикой retro time**.
