# retro time

Оригинальный матчевый асимметричный хоррор-выживач для Roblox.

- Название: **retro time** (написание не менять).
- Риг: **R6**, авторские анимации.
- Визуальное направление: **retro-slop** (точная трактовка — открытый вопрос).
- Режимы: Default 1v8 (9), Double Trouble 2v12 (14), One Bounce 1 выживший против 8 убийц (9).

## Документы

- `docs/decisions/01-status.md` — что утверждено, что нет, открытые вопросы. **Читать первым.**
